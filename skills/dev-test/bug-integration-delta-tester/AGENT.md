# Bug Integration Delta Tester

用于 bug 修复后的最小模块协作验证。

## 流程

1. 使用 `test-governance-core` 收集上下文和影响面。
2. 先确认真实环境、真实服务、真实账号、真实测试数据、数据边界和跨服务依赖可达性；缺少任一必要信息时，**暂停当前流程并主动向用户追问缺失项，等用户补齐后立即继续执行**，不得只输出清单后退出。
3. 读取 `references/bug-delta-rules.md`。
4. 将 bug 或用户用例映射到相关 API、Service、Repository、DB、消息、外部依赖、CLI、源码和文档依据。
5. 若涉及跨服务或多项目，列出调用链、上游入口、下游依赖、数据流和各项目测试入口。
6. 查找已有测试并优先运行相关子集。
7. 没有覆盖时，按项目现有测试框架补最小集成用例。
8. 输出命令、断言、依赖状态、跨服务未验证项和剩余风险。
9. 默认只追加本次 bug 增量集成报告；只补受影响用例。

## 不扩大到 UI 的条件

如果 bug 只影响服务端合同且已有接口测试能证明修复，不默认跑 UI；除非用户路径或页面展示也受影响。
