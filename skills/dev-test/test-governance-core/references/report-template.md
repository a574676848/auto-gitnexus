## 缺陷清单

### 缺陷类型归类

| 缺陷 ID | 关联用例 | 缺陷描述 | 缺陷类型 | 严重程度 | 影响范围 |
| --- | --- | --- | --- | --- | --- |
| | | | 功能/性能/安全/兼容性/易用性/视觉/文档/其他 | P0/P1/P2/P3 | |

缺陷类型定义：

- **功能缺陷**：功能与需求/设计不符，或业务流程中断。
- **性能缺陷**：响应超时、资源占用过高、并发瓶颈。
- **安全缺陷**：越权访问、XSS、SQL 注入、敏感信息泄露。
- **兼容性缺陷**：浏览器/设备/分辨率/操作系统差异导致的问题。
- **易用性缺陷**：交互逻辑不合理、文案歧义、操作路径过长。
- **视觉缺陷**：与设计稿不一致、布局错乱、样式异常。
- **文档缺陷**：API 文档/README/测试文档与实现不一致。
- **其他**：基础设施、日志、告警、监控等。

## 默认落盘路径

| 产物 | 路径 |
| --- | --- |
| 项目测试治理配置 | `test-governance/manifest.yaml` |
| 测试用例矩阵 | `test-governance/test-cases.md` |
| 冒烟测试报告 | `test-governance/reports/YYYY-MM-DD-smoke.md` |
| 集成测试报告 | `test-governance/reports/YYYY-MM-DD-integration.md` |
| UI 视觉比对报告 | `test-governance/reports/YYYY-MM-DD-ui.md` |
| BUG 回归报告 | `test-governance/reports/YYYY-MM-DD-regression.md` |
| 用户澄清记录 | `test-governance/reports/clarifications.md` |
| 截图证据 | `test-governance/evidence/screenshots/` |
| 命令日志 | `test-governance/evidence/logs/` |
| Trace / HAR | `test-governance/evidence/traces/` |

默认增量维护：

- `test-cases.md` 只更新受影响用例，不重排全文件。
- `reports/` 每次新增报告文件，不覆盖历史报告。
- `evidence/` 追加证据文件，文件名包含日期、测试类型或 bug 编号。
- 用户未明确要求全量时，不删除旧报告、不清空旧证据、不重编号测试用例。
