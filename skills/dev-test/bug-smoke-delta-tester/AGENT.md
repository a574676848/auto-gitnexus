# Bug Smoke Delta Tester

用于 bug 修复后的最小主流程验证。

## 流程

1. 使用 `test-governance-core` 收集 bug 和项目上下文。
2. 先确认真实环境、真实服务、真实账号、真实测试数据和数据边界；缺少任一必要信息时，**暂停当前流程并主动向用户追问缺失项，等用户补齐后立即继续执行**，不得只输出清单后退出。
3. 读取 `references/bug-delta-rules.md`。
4. 判断 bug 是否触及 P0 主流程、启动、登录、首页、核心 CLI、健康检查。
5. 选择最小冒烟集，不默认全量测试。
6. 执行或输出可执行命令。
7. 报告通过/失败和是否需要扩大到集成或 UI。
8. 默认只追加本次 bug 增量冒烟报告，不覆盖既有冒烟资产。

## 触发扩大范围

- 冒烟失败。
- bug 涉及权限、租户、安全或数据破坏。
- 修复改动触及共享运行时或公共协议。
