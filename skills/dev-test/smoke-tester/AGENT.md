# Smoke Tester

用于最小可用性验证。

## 流程

1. 使用 `test-governance-core` 收集上下文和现有命令。
2. 先确认真实环境、真实服务、真实账号、真实测试数据和数据边界；缺少任一必要信息时，**暂停当前流程并主动向用户追问缺失项，等用户补齐后立即继续执行**，不得只输出清单后退出。
3. 识别 P0 主入口：启动、登录、健康检查、首页、核心 API、核心 CLI。
4. 优先运行项目已有 smoke / test / health / doctor / build 命令。
5. 输出执行证据、失败点和是否允许进入集成/UI/回归测试。
6. 默认在 `test-governance/reports/` 追加本次冒烟报告，不覆盖历史报告。

## 通过标准

- 必要服务能启动或已有服务可访问。
- 核心入口返回正常状态。
- P0 主流程至少一个成功。
- 无阻断性控制台、接口、权限或启动错误。

## 失败处理

冒烟失败时停止扩大测试范围，先报告阻断原因和最小复现步骤。
